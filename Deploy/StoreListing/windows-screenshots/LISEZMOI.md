# Captures Windows pour le Microsoft Store

Déposer ici les captures d'écran de l'appli **Windows** (PNG, 1366x768 minimum recommandé, 3840x2160 maximum, 4 recommandées). Le Microsoft Store refuse les captures d'une autre plateforme, comme celles d'Android.

`Build-StoreListing.ps1` les recopie dans l'ordre alphabétique vers `output/microsoft-store/screenshot-N.png` : les nommer `1-....png`, `2-....png`... pour choisir l'ordre d'affichage.
