# Captures Windows pour le Microsoft Store

Déposer ici les captures d'écran de l'appli **Windows** (PNG, capture de la fenêtre seule, 4 recommandées). Le Microsoft Store refuse les captures d'une autre plateforme, comme celles d'Android.

`Build-StoreListing.ps1` les centre dans une image 1920x1080 sur le fond de l'appli, dans l'ordre alphabétique, vers `output/microsoft-store/screenshot-N.png` : les nommer `1-....png`, `2-....png`... pour choisir l'ordre d'affichage.
