Supprimer tes données

Dernière mise à jour : 28 novembre 2026

Cette page explique comment demander la suppression des données liées à Resonance (développeur : Narfedome).

Les données sur ton appareil

Tout ce que tu crées dans Resonance reste sur ton appareil et n'est jamais envoyé à un serveur. Pour le supprimer, désinstalle l'application ou efface ses données (Android : Paramètres › Applications › Resonance › Stockage › Effacer les données). Le développeur n'en a aucune copie.

Les messages envoyés depuis « Nous écrire »

Seuls les messages que tu as choisi d'envoyer depuis Paramètres › « Nous écrire » sont conservés par le développeur. Pour les faire supprimer :

  1. écris à narfedome.support@gmail.com avec l'objet « Suppression de mes données - Resonance » ;
  2. indique la date approximative de l'envoi et le résumé (la phrase) de ton message : aucun compte ni identifiant n'étant demandé, c'est ce qui permet de le retrouver ;
  3. tu reçois une confirmation une fois la suppression faite, au plus tard sous 30 jours.

Ce qui est supprimé

  • le message (type, résumé, détail) ;
  • les captures d'écran jointes ;
  • les informations techniques jointes (version de l'appli, modèle et système de l'appareil, langue, dernières lignes du journal d'erreurs).

Ce qui est conservé, et combien de temps

  • rien après ta demande : aucune copie du message n'est gardée ;
  • sans demande de ta part, un message est conservé le temps de traiter le problème, puis au plus 12 mois après sa clôture ;
  • des données techniques temporaires, sans le contenu du message, sont effacées automatiquement : un compteur d'envois par adresse IP (1 heure) et l'identifiant aléatoire du message, qui évite les doublons (30 jours).
