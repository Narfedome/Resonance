Changelog

What's new in each Resonance update, in order. Current version: 1.0.143.

1.1

July 2026
  • DM Tools is now Resonance: new name, new splash screen and new website, resonance-app.com.
  • Android: the app will now be distributed through Google Play, the APK is no longer offered as a direct download.
  • Resonance installs as a new app: to keep your campaigns and library, export them as .dmpack from DM Tools before updating, then import them into Resonance.
  • New support address: narfedome.support@gmail.com.
  • The Audio Mixer can now be used without going through a Scene: a freeform scene is always available from the AudioMixer tab.
  • Pick a campaign, then a chapter, then a scene directly from the mixer, without going back to the Campaigns accordion.
  • Drag-and-drop reordering for a scene's tracks, mixer channels, and the Campaigns/Chapters/Scenes accordion.
  • The mixer's navigation arrows now move to the next or previous chapter at the end of a scene, instead of getting stuck.
  • Library grouped by category.
  • Much faster .dmpack export and import.
  • A track's volume and fade in/out are now shown directly on its card in the mixer.
  • Improved contrast for the "Forêt profonde" and "Acier & brume" themes.
  • Imported tracks' covers are ready immediately after an import, and its total duration is shown.
  • Fixed a freeze when picking a large file to import on Android.
  • Fixed the Library slowing down right after an import.
  • Fixed the app freezing when opening Settings while the storage size was being calculated.
  • Fixed the Library's empty state briefly flashing before loading finished.
  • Fixed track order sometimes getting shuffled after a library import.

1.0

July 2026
  • Windows interface resized for mouse use: denser fonts, buttons and spacing, less tailored for touch.
  • Fixed the mixer's volume slider not displaying correctly on Windows.
  • Fixed audio playback failing on some files on Windows.
  • Dialogs (rename, create, edit a track...) now properly centered on Windows instead of appearing stuck to the top of the window.
  • Library: fixed-size tiles arranged in columns based on window width, instead of stretching full-screen.
  • Redesigned Categories and Import/Export pages for Windows, with a clean back button.
  • Tightened Campaigns accordion spacing on Windows for better readability.
  • Fixed background watermark not showing on Windows.
  • New accordion-style Campaigns explorer, faster to navigate mid-session.
  • Bigger tap targets on the accordion, no more pixel-precise taps.
  • Fixed import of custom categories.
  • Exported packs (.dmpack) are now named after their actual content instead of a generic name.
  • Android startup icon now properly framed on recent devices.
  • Long track names are cleanly truncated instead of breaking the layout.
  • Removed the mixer's loop button, redundant with the per-track settings.
  • Resizable mixer volume slider that fills the available space instead of a fixed length.
  • Track names now display in full instead of getting cut off or overlapping other elements.
  • Progressive scene loading: each track appears as soon as it's ready, instead of one blocking loading screen for the whole scene.
  • Same loading feedback whether you launch a scene from the Campaigns accordion or from the mixer itself.
  • Freely resizable window on Windows.

0.2

July 2026
  • Import and export of whole campaigns and libraries (.dmpack packs), signed to detect tampering.
  • Redesigned dialog system (confirm, input, edit) for a more consistent experience.
  • Track editing in a popup window instead of a dedicated page.
  • Advanced per-track settings: loop and fade-out.
  • Faster library loading.
  • Built-in bug report button.
  • Automatic capitalization at the start of text fields.
  • Numerous fixes (audio mixer, dialogs, onboarding language selection, import cache).

0.1

February – July 2026
  • First public release (under the name DM Tools).
  • Multi-track audio mixer with independent play, loop and stop per track.
  • Track and spell library, reusable across campaigns.
  • Organization by campaign, chapter and scene.
  • Visual themes and French/English translation.
  • Windows installer and Android APK.
